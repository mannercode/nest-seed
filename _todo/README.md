## 서비스별 확장 보류

| 항목     | 실제 서비스에서 결정할 내용                                        | 문서                      |
| -------- | ------------------------------------------------------------------ | ------------------------- |
| A3·A4·A5 | 토큰·세션 정책 확대, 계정별 로그인 제한, 비밀번호 재인증·분실 복구 | [인증](authentication.md) |
| U3·U4    | 이메일 확인·변경 승인, 계정 정지·탈퇴 후 관련 데이터 처리          | [사용자](users.md)        |
| R3       | 관리자 역할 세분화·관리 기능                                       | [권한](authorization.md)  |

보류 항목은 시드 완료 조건에서 제외한다. 현재 제공하는 토큰·로그인 제한의 계약은 [앱 가이드](../apps/README.md#http와-인증-계약)를 유지하며, 확장이 필요한 사용처와 정책·외부 서비스가 정해질 때 재검토한다.

소셜 로그인·MFA·패스키, 조직·멀티테넌트 권한, 범용 권한 엔진, 미디어 변환·파일 버전 관리도 구체적인 사용처가 정해질 때까지 보류한다. 메일을 도입할 때는 계정 확인·복구에 필요한 범위부터 검토한다.
