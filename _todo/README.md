진행 대상은 [시드의 범위](../apps/README.md#시드의-범위)에 맞춰 현재 제공하는 기능의 정확성 검증과 예제 설명 정리로 한정한다. `libs/`의 공개 계약과 지원 입력 범위는 [공유 패키지 검토 기준](../AGENTS.md#영역별-판단-기준)을 따른다.

## 기존 기능 검증·수정

| 항목  | 남은 작업                                                        | 문서                     |
| ----- | ---------------------------------------------------------------- | ------------------------ |
| R1·R2 | 현재 HTTP·SSE 경로의 역할 제한과 자원·작업 조회 권한 검증        | [권한](authorization.md) |
| F2~F4 | 현재 영화 이미지의 확정·삭제·만료 정리에서 경합과 부분 실패 재현 | [파일](files.md)         |
| CI    | Stability의 NATS 연결 실패 원인 조사                             | [CI](ci.md)              |

R1·R2와 F2~F4는 아직 결함을 확정하지 않은 검증 대상이다. 기존 테스트를 대조하고 실행 순서를 제어해 확인한 뒤, 현재 계약을 어기는 부분의 영향과 최소 수정 범위를 정한다. CI 연결 실패는 실제 관찰했지만 원인은 미확인이다.

## 서비스별 확장 보류

| 항목     | 실제 서비스에서 결정할 내용                                        | 문서                      |
| -------- | ------------------------------------------------------------------ | ------------------------- |
| A3·A4·A5 | 토큰·세션 정책 확대, 계정별 로그인 제한, 비밀번호 재인증·분실 복구 | [인증](authentication.md) |
| U3·U4    | 이메일 확인·변경 승인, 계정 정지·탈퇴 후 관련 데이터 처리          | [사용자](users.md)        |
| R3       | 관리자 역할 세분화·관리 기능                                       | [권한](authorization.md)  |
| F1       | 사용자 파일·비공개 첨부 등 파일 API의 새 사용처                    | [파일](files.md)          |

보류 항목은 시드 완료 조건에서 제외한다. 현재 제공하는 토큰·로그인 제한의 계약은 [앱 가이드](../apps/README.md#http와-인증-계약)를 유지하며, 확장이 필요한 사용처와 정책·외부 서비스가 정해질 때 재검토한다.

소셜 로그인·MFA·패스키, 조직·멀티테넌트 권한, 범용 권한 엔진, 미디어 변환·파일 버전 관리도 구체적인 사용처가 정해질 때까지 보류한다. 메일을 도입할 때는 계정 확인·복구에 필요한 범위부터 검토한다.
