# 전체 프로젝트 검토

기준 커밋은 `6bbe8cdf7df05ce9aa69cd6ab116f8ccde3fb7f0`, 검토일은 2026-09-26이다. 변경 diff가 아니라 해당 시점의 추적 파일 611개 전체를 검토했다. 기존 로컬 커밋 2개를 포함하며, 소스·설정은 변경하지 않았다.

## 판단

API 본체와 재사용 라이브러리, 작은 연결 데모라는 시드의 목적과 현재 폴더 구조는 대체로 맞는다. 단순 CRUD에서 여러 도메인의 협력·분산 실행으로 읽는 순서도 성립한다. 다만 정상적으로 허용한 입력을 다음 단계가 처리하지 못하는 연결과, 공통 유틸·테스트 도구의 경계 조건에 실제 결함이 남아 있다. 기존 검사가 통과한다는 사실만으로 이 부분의 정확성을 판단할 수 없다.

수정 대상으로 삼는 것은 아래 5개 항목이다. 기존 예제의 계약과 검증을 명확히 하면서 읽기 부담을 작게 유지할 수 있는 수정에 한정한다. 드문 입력의 오류나 선택적 정리는 발견 사실을 남기되 필수 작업으로 삼지 않는다.

## 작업 선정 기준

[저장소의 검토 기준](../../AGENTS.md#10-시드의-목적과-읽기-부담을-기준으로-검토한다)을 따른다. 아래 5개 항목은 핵심 예제와 재사용 코드를 기존 소유 지점에서 작게 바로잡는 범위로 선정했다. 회귀 검증은 기존 테스트에서 해당 보장을 직접 확인하고, 바뀐 계약을 소유하는 문서만 갱신한다.

## 진행할 작업

- [ ] **API-1 · 중복 좌석 생성 방지** — 같은 좌석의 티켓이 각각 판매되는 것은 예제의 정합성 전제를 깨뜨린다. 기존 SeatmapSchema에서 좌표 중복을 거부하고 생성·수정 경로를 기존 테스트로 검증한다. 새 좌석 모델이나 유일성 관리 계층은 만들지 않는다. [근거](api.md)
- [ ] **API-2 · 0좌석 상영 조회** — 허용된 입력으로 생성한 상영을 조회할 수 있어야 한다. 기존 집계·조합 지점에서 0좌석의 판매 집계를 0으로 표현하고 생성 후 조회를 검증한다. 0좌석 금지나 다른 집계 오류를 숨기는 처리는 범위에 없다. [근거](api.md)
- [ ] **TD-01 · 구매 경쟁 테스트의 기대값** — 예제의 검증이 잘못된 판매 수량을 통과시키지 않도록 한다. 기존 단언의 기대값을 원 요청의 티켓 목록으로 바꾸고, 부분·과다 판매 결과를 거절하는지 확인한다. [근거](tests-demos.md)
- [ ] **L2 · SSE UTF-8 처리** — 정상 한글을 읽기 위해 청크별 문자열 변환을 표준 스트림 디코딩으로 교체한다. 기존 테스트에서 문자 바이트가 나뉘어도 원문이 유지되는지 확인한다. 자체 디코더나 SSE 기능 확장은 필요 없다. [근거](libs.md)
- [ ] **API-3 · 결제 부분 인덱스 사용** — 복사해서 쓸 조회 예제가 기존 인덱스를 활용하도록 조회 조건을 맞춘다. explain으로 기존 부분 인덱스 사용을 확인한다. 새 인덱스·쿼리 추상화·성능 검증 체계는 추가하지 않는다. [근거](api.md)

검증 스택과 재현용 DB는 종료·삭제했다. 기존 개발 인프라를 reset하거나 기존 사용자 데이터를 삭제하지 않았다. 기존 테스트와 API 문서는 자신의 fixture 데이터를 만들며, 인프라 데이터 전체를 실행 전으로 되돌렸다는 뜻은 아니다.

`pnpm run atoz` 전체, 공유 Restate를 SIGKILL하는 복구 테스트, 장시간 race·benchmark·반복 CI는 이 검토에서 새로 실행하지 않았다. 기존 원격 통과 이력은 참고 자료이며 현재 로컬 커밋의 새 실행 결과로 계산하지 않는다. 모든 입력·장애 조합과 신규 사용자의 처음 설치 경험까지 증명한 검토는 아니다.

## 완료 기준

진행할 5개 항목의 보장을 기존 테스트와 필요한 실제 검증으로 확인하고, 변경된 workspace의 필수 검사도 통과한다. 수정 diff에는 각 문제 해결에 필요한 코드·테스트·문서만 남기며 읽기 부담을 불필요하게 늘리는 분기·추상화를 추가하지 않는다. 보류 항목을 모두 해결하는 것은 완료 조건이 아니다.

이번 작업은 검토 결과 작성까지다. 소스·설정 수정, 새 테스트 파일, 새 의존성·보안 정책은 적용하지 않았다.
